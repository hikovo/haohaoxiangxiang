# 好好想想

有三好兔陪伴的小空间。一起收好日常的小事与心情，想小苏的时候也能翻翻照片、视频和与灯书 ˈ ᵕ ˈ ♡

## 下载安装

[下载 2.0.0 安装包](https://github.com/hikovo/haohaoxiangxiang/releases/tag/v2.0.0)

- 适用于 **Android 8.0 及以上的 64 位 ARM 手机**（arm64-v8a），例如小米、OPPO、vivo、荣耀、三星、一加、realme 等品牌的符合要求的机型。
- **华为手机需支持安装 Android APK**；本包不是原生鸿蒙应用，HarmonyOS NEXT 及后续系统的兼容环境未验证，不保证桌宠与提醒可用。可参考 [华为安装说明](https://consumer.huawei.com/cn/support/content/zh-cn16061787/)。其他兼容系统也可尝试，具体功能以设备实际支持为准。
- 品牌仅作参考，不代表所有机型均已测试。桌宠需要悬浮窗权限，提醒效果也受手机通知与声音设置影响。
- 安装包约 185 MB，包含离线回看的素材。下载 APK 后按手机提示安装即可。
- **iOS 版正在推进中**，可以关注本仓库的后续更新。

## 功能

互动与桌宠、每日询问与提醒、专注计时、待办事项、倒数日与纪念日、便签本与碎碎念、素材回看与收藏。便签支持插入图频，图片可裁切与缩放。

## 开发

页面使用 TypeScript / Vite，原生部分使用 Tauri / Rust / Kotlin。使用 Node.js 22.12 或更新版本：

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm dev --host 127.0.0.1
```

手机页面预览地址：`http://127.0.0.1:1420/?mobile=1`。

源码包含页面、原生模块、功能说明书与专项检查，**不包含角色图形、动画及第三方媒体**，因此无法直接重建完整发行版。资源接入与构建准备见 [构建说明](docs/ASSETS.md)。
