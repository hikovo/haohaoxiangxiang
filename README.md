# 好好想想

有三好兔陪伴的小空间。收好日常的小事与心情，想小苏的时候，就一起翻翻照片、视频和与灯书 ˈ ᵕ ˈ ♡

## 把兔兔带回家

[下载 2.0.0 安装包](https://github.com/hikovo/haohaoxiangxiang/releases/tag/v2.0.0)，打开 APK，按手机提示安装即可。安装包约 185 MB，包含离线回看的素材。

- 适用于 **Android 8.0 及以上的 64 位 ARM 手机**（arm64-v8a），例如小米、OPPO、vivo、荣耀、三星、一加、realme 等品牌的符合要求的机型。
- **华为手机需支持安装 Android APK**。本版本不是原生鸿蒙应用，不保证鸿蒙兼容环境下的功能可用。
- 手机品牌仅作参考，不代表所有机型都已测试。桌宠需要悬浮窗权限；提醒请开启通知、铃声与震动，后台运行也会影响提醒效果。
- **iOS 版正在推进中**，苹果持续揉面中，可以关注后续消息喔～

## 兔兔能陪你做什么

- **互动与桌宠**：跳跳、wink、拖动和调整大小，也能开启悬浮陪伴。
- **每日询问与提醒**：写下想问的话，选好时间，让兔兔记着。
- **专注计时**：按分钟和秒数设置倒计时，支持暂停与继续。
- **待办事项**：日常和追星的小事放在一起，完成一件就勾一下。
- **倒数日与纪念日**：记着还有多久，也记着已经多久。
- **便签本与碎碎念**：收好长短心情，便签支持插入图频，图片可以裁切与缩放。
- **说说话**：按关键词或日期翻翻照片、视频和与灯书，喜欢的可以收藏。
